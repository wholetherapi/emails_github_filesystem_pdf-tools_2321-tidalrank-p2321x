# TidalRank

> **Status: To be released.** The implementation is still being prepared for the
> camera-ready release and will be published in this repository after the conference.

Placeholder repository for the official implementation of **TidalRank: Calibrated
Learning-to-Rank for Noisy Query Streams** (WSDM 2027).

## About the paper

TidalRank studies calibrated learning-to-rank under noisy query streams. The paper has
been accepted at WSDM 2027.

## Repository layout (work in progress)

- `src/` - ranking model and calibration components (being cleaned up)
- `configs/` - experiment configurations
- `experiments/` - evaluation scripts
- `data/` - dataset preparation notes
